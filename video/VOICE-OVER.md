# Turnout demo, voice-over (about 80 seconds)

Generic on purpose: the agent and the crowd, no vendor names, the promise at the end. The
captions and the chapter tags on screen carry the same words. The voice is generated with
edge-tts (`npm run voice`, voice `en-US-AvaMultilingualNeural`); change `VOICE=` to try another.
